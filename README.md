# uvm_hierarchy_viz
A detailed visualization of UVM.

## 🗺️ Freeplane Viewer

For an offline and more detailed mind-map view, you can download the **Freeplane mind-map file** included in this repository.

### How to view

1. Download the `.mm` file from this repository.
2. Install **Freeplane**.
3. Open the downloaded `.mm` file with Freeplane.
4. Expand/collapse nodes and navigate through the complete UVM hierarchy.

### ⬇️ Download Freeplane

 **[Download Freeplane](https://docs.freeplane.org/getting-started/getting-started.html)**

Freeplane is a free and open-source mind-mapping application.
